## 6. R5-1 应有的验收口径（防止假通过）

每条验收必须同时记录：完整命令、退出码、测试/检查数量、失败项、执行环境、日志路径。

- Lint PASS：`ruff check .` 退出码 0。
- Format PASS：`ruff format --check .` 退出码 0，**不得**通过新增排除规则获得。
- Type Check PASS：`mypy ...` 退出码 0；若豁免必须有明确批准与范围。
- Python Tests PASS：全量 pytest 退出码 0，basetemp 预建且独立于业务库。
- Frontend Build PASS：`npm ci` + `npm run build` + `npx vue-tsc --noEmit` 全 0。
- Browser E2E PASS：真实 Chrome，14+ 页面、主要交互、console/4xx 零错误，多分辨率含 1920×1080 与 768px。
- Security Regression PASS：`test_security_r4.py` + sandbox paths + storage 全通过。

禁止：删除失败测试、修改断言迎合结果、Mock 冒充 LLM 或浏览器执行、
把 SKIPPED/BLOCKED/NOT_RUN 计为 PASS、只展示成功截图。
