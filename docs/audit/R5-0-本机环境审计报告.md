## 5. 服务与网络边界（实测）

- 8000 / 8001 / 8077 **均无监听**，本机当前没有 TraceGuard 服务在运行。
- `packages/core/config.py`：`api_host = "127.0.0.1"`、`teamflow_host = "127.0.0.1"`；
  `scripts/serve.py --host` 默认 `127.0.0.1`。未见本项目配置 `0.0.0.0`、隧道或公网暴露。
- 机器上存在其他 `0.0.0.0` 监听（53/135/445/902 等）和多个 Chrome / Node 进程，
  这些属于操作系统与 IDE 会话，**不是本项目启动的进程**，本轮未尝试识别归属或终止。
- 外部网络：本轮未访问任何外部站点，未调用任何模型，未上传任何数据。
