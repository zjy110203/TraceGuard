## 3. 核心架构与事务

新增 CandidateTransactions；CandidateStore、审核路由和 compile 共用 Candidate 级锁，顺序 Candidate → Case，正式文件所有权/字节 SHA-256 验证后才能恢复。Intent 先持久化，已存在无归属文件保留 BLOCKED；未完成 Intent 预留 Case ID；拒绝也持久化决策；恢复验证前后快照、完整审核字段与正式文件。单进程线程锁，不是跨进程协议。

原子写入为同目录临时文件、完整 JSON、flush/fsync、os.replace，无先删除目标。存储 envelope `_candidate_transaction` 由 loader 剥离，不改活动 TestCase schema、Oracle 或历史正式版本。启动恢复结果进入 health.candidate_recovery 和日志。

原始 f68de9b 的跨文件孤儿缺口已用独立 Python 子进程 os._exit(74) 实际复现。新协议 os._exit(73) 专项覆盖 Intent 前后、正式/状态临时文件与替换前后、DONE、恢复再次退出和重复恢复。真实 HTTP 并发覆盖五类操作，检查单终态、审核记录与文件归属。
