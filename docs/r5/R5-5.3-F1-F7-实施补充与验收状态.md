## 安全与数据边界

- 正式 API/TeamFlow 只能由 `scripts.serve` 在 loopback 校验后授权启动；test 配置使用明确隔离的 `APP_ENV=test`。
- `ExecutionAuthorizationManager` 的授权消费在 Browser Adapter 私有执行入口内检查；直接调用适配器不带授权会被拒绝。
- Scenario secret 使用白名单 `teamflow.password → TG_SECRET_TEAMFLOW_PASSWORD`。dev/prod 读取环境变量；test 映射只存在于测试配置。Trace 保存 `[TG_SECRET_REF]` 或脱敏值，不保存口令。
- Trace v3 保留 v1/v2 旧语义，覆盖 DecisionRecord、提议动作、策略判断、决策来源/ID 与场景 ID/version/digest；Scenario Digest 使用 canonical JSON、递归排序、UTF-8、`allow_nan=false` 和 SHA-256。
- Repair 仍要求人工 Reviewer、独立 Operator、成功 Sandbox Replay 和 CAS；Mock Agent 不审批、不晋升。
