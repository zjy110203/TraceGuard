## 1. Scenario Registry（🔧 扩展）

**模块**：`packages/agents/scenarios.py`（保持唯一注册点；Explorer 核心零场景分支）。

### 1.1 输入

| 参数 | 类型 | 说明 |
|---|---|---|
| `scenario` | `Scenario`（frozen dataclass） | 场景包实例，字段见设计 §2.2 |
| （新增）`version` | `str` | SemVer；与 `scenario_id` 组成唯一键 |
| （新增）`preconditions` / `data_setup` / `cleanup` / `denied_actions` / `paths.*` | 结构化字段 | 见数据契约 §A |

### 1.2 输出

| 返回 | 说明 |
|---|---|
| `register()` → `Scenario` | 注册成功返回；失败抛 `ValueError` |
| `require(id, version)` → `Scenario` | 精确版本取用；执行时锁定并写入 Trace |
| `all()` / `implemented()` → `tuple[Scenario, ...]` | 查询 |
| `public_view()` → `dict[str, str]` | 兼容旧客户端（id → description） |
| `validate_all()` → `dict[str, list[str]]` | 问题清单（空 = 全部合法） |

### 1.3 依赖

`goal_assertions.validate_assertion`（断言定义校验）、`KNOWN_ACTIONS`（工具白名单）。

### 1.4 权限

- 注册操作仅限进程内构建期（`build_default_registry` / 测试装配），**不暴露远程注册 API**；
- 远程侧只有读（`GET /explorations/policies` 暴露意图模板），保持现状。

### 1.5 错误处理

| 情况 | 行为 |
|---|---|
| 结构非法（空字段/非法 origin/未知工具/空 constraints…） | `ValueError`，拒绝注册 |
| `(scenario_id, version)` 重复 | `ValueError`，不静默覆盖 |
| `implemented=True` 但 `paths.normal` 为空 | 拒绝注册 |
| `denied_actions ∩ allowed_actions ≠ ∅` | 拒绝注册 |
| 未实现场景被执行 | API 返回 `UNSUPPORTED_SCENARIO` + `blocked_reason`（现状语义保持） |

### 1.6 测试要求

- 注册表校验参数化（每条 validate 规则一个用例）；
- 版本并存：同 id 不同 version 可注册、同 id 同 version 拒绝；
- 四类路径（正常/异常/边界/恢复）步骤工具越界 → 拒绝；
- 回归：现有 26 项定义层用例全过（不降断言）。

### 1.7 版本兼容性

- `to_dict()` 只增字段不改不删；旧客户端忽略新增字段；
- `public_view()` 形状不变；
- 旧 Trace 中的 `scenario_id` 无 `scenario_version` 时视为 `1.x` 历史记录，不重写。

## 2. Context Builder（🆕 新增）

**模块**：`packages/agents/context_builder.py`（新建，职责单一）。

### 2.1 输入

| 参数 | 来源 | 说明 |
|---|---|---|
| `intent` | C01 TestIntent | goal / target / expected_outcomes / constraints |
| `observation` | `Observation v2` | 当前页面结构化观测 |
| `history` | `ExplorationTrace` | 历史 Action + 结果（已脱敏） |
| `budget_state` | `Budget` | 剩余步数/时长/工具调用/（M4）费用 |
| `goal_state` | `GoalEvaluator` 最近结论 | 当前目标状态 |
| `scenario` | `Scenario` | allowed/denied_actions、constraints、paths |

### 2.2 输出

`DecisionContext`（结构化 dict / dataclass）：组装后的模型输入上下文，
含各来源的规范化字段与 `context_version`。

### 2.3 依赖

`exploration.intent_of`（意图规范化）、`sanitize_action`（历史动作脱敏）、Observation v2 读取器。

### 2.4 权限

只读；**不得**读取输入值/凭据明文（凭据仅在动作参数替换时来自受信配置，不进上下文）；
prompt 组装时对 password/敏感 selector value 做脱敏替换（复用 `redact_actions`）。

### 2.5 错误处理

| 情况 | 行为 |
|---|---|
| 观测缺失 | 上下文标记 `observation_missing`，Planner 只能输出 snapshot/navigate 类恢复动作 |
| 历史为空 | 正常（首步） |
| 场景缺失 | 拒绝构建（探索必须绑定场景） |

### 2.6 测试要求

- 确定性：相同输入 → 相同上下文（字节级稳定，便于 prompt hash）；
- 脱敏断言：上下文任何字段不得含明文密码；
- 字段完整性：7 类输入各有对应输出字段。

### 2.7 版本兼容性

`context_version` 进入 Trace 与 prompt hash；上下文格式变更升版本号，旧版本可复算（存 raw 输入引用）。

## 3. Agent Planner（🔧 扩展）

**模块**：`packages/agents/exploration.py`（`Policy` Protocol）+ `scripted_agent.py` +（M4）真实策略。

### 3.1 输入

`DecisionContext`（§2 输出）。

### 3.2 输出

`Action Proposal`（结构化，见数据契约 §B）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `decision_id` | ✅ | `dec_<uuid>` |
| `action` | ✅ | ∈ KNOWN_ACTIONS |
| `arguments` | ✅ | 结构化参数（selector/url/value…） |
| `rationale` | ✅ | 决策理由（人类可读，进 trace） |
| `expected_effect` | ✅ | 预期页面变化（执行后比对） |
| `confidence` | ✅ | 0~1，仅审计，不作放行依据 |
| `prompt_version` / `model_version` | 真实阶段 ✅ | Scripted/Mock 用 NOT-REAL 标记 |

**空决策**（`None`）合法：Planner 判定无动作可做 → 停止（`PLAN_EXHAUSTED` 或 `POLICY_STOP`）。

### 3.3 依赖

LLM Provider（§8）或 Scripted 脚本；Context Builder；`ToolCall` 既有结构。

### 3.4 权限

- Planner **只能产出提案**，不能执行；执行唯一入口是 ToolGateway；
- 不能声明 GOAL_VERIFIED（verdict 只属于 Goal Evaluator）；
- 不能读取 GT（Benchmark GT 隔离红线）。

### 3.5 错误处理

| 情况 | 行为 |
|---|---|
| Structured Output 不合法 | `StructuredOutputError`，不产生决策；按 §5.4 降级或停止 |
| Provider 不可用 | `ProviderUnavailable`，探索报 LLM unavailable（不静默换脚本冒充） |
| 提案违反 schema（未知字段/类型错） | 拒绝提案，记 `policy_decision=invalid-proposal` |
| Scripted 脚本耗尽 | `PLAN_EXHAUSTED`（现状语义） |

### 3.6 测试要求

- Proposal schema 参数化校验（合法/非法字段矩阵）；
- 重复/危险动作检测（同参数连续 2 次 → POLICY_STOP）；
- MockProvider 闭环：观测变化 → 提案变化（决策确实"看"了页面）；
- 回归：现有 `test_scripted_agent.py` / `test_planner.py` / `test_llm_exploration.py` 全过。

### 3.7 版本兼容性

- `Policy.next_action(observation) -> ToolCall | None` 旧签名保留为兼容视图，
  新代码走 `propose(context) -> ActionProposal | None`；
- `agent_version` 命名规范保持（含 `-NOT-LLM` / `-NOT-REAL-INFERENCE` 后缀纪律）；
- Trace Hash v3 覆盖 proposal 全字段；v2/v1 记录按旧规则校验。

## 4. Policy Validator（🔧 扩展）

**模块**：从 `ToolGateway.authorize` 中拆出独立校验阶段（或作为其前置子模块），
对应设计 §4.3 六项检查。

### 4.1 输入

| 参数 | 说明 |
|---|---|
| `proposal` | Action Proposal |
| `scenario` | allowed/denied_actions、constraints |
| `budget_state` | 剩余预算 |
| `history` | 重复/危险检测用 |

### 4.2 输出

`PolicyDecision`（结构化）：`allowed: bool` + `reason_code` + `detail`；
reason_code ∈ `ok / unknown-action / not-allowed-by-scenario / origin-denied /
denied-action / budget-exceeded / duplicate-or-dangerous / invalid-proposal`。

### 4.3 依赖

`OriginPolicy`/`Budget`（exploration.py）、场景约束、历史动作记录。

### 4.4 权限

安全边界执行者：**任何检查失败都不得放行**；`origin-denied` 额外触发 `POLICY_STOP`
（越界一次即停，不给重试机会）。禁止用配置放宽 OriginPolicy。

### 4.5 错误处理

- 检查自身异常（如预算状态缺失）→ 拒绝放行（fail-closed），记 `invalid-proposal`；
- 不吞异常：校验器崩溃必须让探索以 `ERROR`/`EXECUTION_FAILED` 停止，不静默继续。

### 4.6 测试要求

- 六项检查逐项用例（含边界：允许 origin 带端口精确比对）；
- fail-closed 用例（校验器异常 → 不放行）；
- 回归：`test_explorer_security.py` / `test_network_gateway.py` / `test_security_r4.py` 全过。

### 4.7 版本兼容性

`PolicyDecision` 为新增记录结构，进 Trace（`policy_decision` 字段）；
不改变既有 `ToolGateway.authorize` 抛错语义（拒绝仍是异常/返回码双通道中的一种，实施时保持现状签名）。

## 6. Goal Evaluator（🔧 扩展）

**模块**：`packages/agents/goal_assertions.py` + `exploration.evaluate_goal`。

### 6.1 输入

| 参数 | 说明 |
|---|---|
| `intent` | C01（target / expected_outcomes） |
| `goal_definition` | 场景断言列表（10 类 + 新 10 类） |
| `observations` | Observation v2 序列（含 dom_counts/dom_relations） |
| `bindings` | 动态绑定表（`{unique_suffix}` 等，`dynamic_match` 用） |

### 6.2 输出

`AssertionReport` / `GoalEvaluation`（现状结构）：
`verdict`（VERIFIED / NOT_VERIFIED / INCONCLUSIVE / NOT_EVALUATED）
+ 逐项 `AssertionResult`（name/kind/verdict/expected/observed/evidence/required/detail）。

### 6.3 依赖

Observation v2 采集器；`_path_matches`（单段通配，编译准入共用）。

### 6.4 权限

- **verdict 裁决权唯一归属**：Agent/Planner/模型不得写 verdict；
- 断言只收紧 Compiler 准入，永不放宽；
- 不读输入值（form_state 只报 presence/visibility/disabled）。

### 6.5 错误处理

| 情况 | 行为 |
|---|---|
| 观测不可用 | `INCONCLUSIVE`（永不 FAILED） |
| 断言定义非法 | `AssertionDefinitionError`（加载期拒绝，不进运行期） |
| 绑定缺失（dynamic_match） | `INCONCLUSIVE` |
| 前观测缺失（page_transition） | `INCONCLUSIVE` |

### 6.6 测试要求

- 新 kind 逐项参数化（PASSED/FAILED/INCONCLUSIVE 三态）；
- 语义保持 7 条逐条用例（含"VERIFIED 可被断言收紧"）；
- 读取时复算 `goal_assertions_verified` 一致性；
- 回归：`test_goal_semantics.py` / `test_agentic_scenarios.py`（34 项）全过。

### 6.7 版本兼容性

`AssertionResult.to_dict()` 只增字段；旧报告读取不受影响；
`goal_definition` 新 kind 对旧校验器是"未知 kind"——**加载期即拒绝**（定义错误不静默忽略，
与现状 `SUPPORTED_KINDS` 纪律一致），因此场景包必须与运行器同版本部署。

## 7. Trace Recorder（🔧 扩展）

**模块**：`packages/agents/exploration.py`（`ExplorationTrace` / `compute_trace_hash` /
`verify_trace_record`）+ `llm.CallTrace`。

### 7.1 输入

决策链各步记录：observation_ref、Action Proposal、PolicyDecision、execution_result、
goal_evaluation、evidence_refs、token_usage/cost、stop_reason。

### 7.2 输出

- `ExplorationTrace.to_dict()` → 持久化记录（ExplorationStore JSON）；
- `compute_trace_hash` → **v3 哈希**（覆盖 proposal/policy_decision/decision_id）；
- `verify_trace_record` → 布尔 + 版本感知。

### 7.3 依赖

`sanitize_action` / `redact_actions`（脱敏）、hashlib、ExplorationStore。

### 7.4 权限

- 只追加不改写（append-only 纪律）；
- 敏感内容（密码/输入值/prompt 明文）禁止入 Trace（prompt 只存 sha256）；
- GT 不入 Trace。

### 7.5 错误处理

哈希校验失败 → `verify_trace_record=False` + 明确 reason（篡改/截断/版本不符）；
模型失败 → 空决策 + 失败事件入链（不伪造决策）。

### 7.6 测试要求

- 三版本哈希矩阵（v1/v2/v3 记录各自校验通过、跨版本篡改可检出）；
- 决策链关联完整性（decision_id 单链回放）；
- 脱敏断言（trace 无明文密码）；
- Scripted 可重放一致性；Real 复核视图字段齐备（M4）。

### 7.7 版本兼容性

- **v1/v2 历史记录不迁移、不改写**，按 `trace_hash_version` 分派校验器；
- 新字段全部可选；缺失表示"当时没有"，不判篡改；
- C05 零改动（Trace 属探索记录域，不进 C05 事件 Schema）。

## 8. LLM Provider（🔧 扩展）

**模块**：`packages/agents/llm.py`（`LLMProvider` Protocol / `TracedClient` / `provider_from_env`）。

### 8.1 输入

`messages: list[Message]` + `ModelConfig` + 可选 JSON Schema。

### 8.2 输出

`LLMResponse`（text/provider/model/latency/attempts/may_contain_real_inference/
prompt_tokens/completion_tokens）；`TracedClient.complete_structured` → 校验后的 dict。

### 8.3 依赖

httpx、jsonschema（Draft202012Validator）；环境变量（`DEEPSEEK_API_KEY` / `OPENAI_API_KEY`）。

### 8.4 权限

- **三模式区分不可混淆**：ScriptedProvider / MockProvider（🆕）/ OpenAICompatibleProvider（Real）；
- `is_real_model` 硬标记；Scripted/Mock 的结果永不标注真实推理；
- 真实调用受 D8 门禁 + 人工启用开关（M4）；当前 409 BLOCKED 不解除；
- 密钥只按环境变量**名**检查，值不读取、不日志、不入 Trace。

### 8.5 错误处理

| 情况 | 行为 |
|---|---|
| 无密钥 | `provider_from_env()` 返回 `None` / 构造抛 `ProviderUnavailable`，不伪造 provider |
| HTTP 4xx/5xx / 超时 | 重试 `max_retries` 次后抛 `LLMError` |
| 结构化输出不合法 | `StructuredOutputError`，重试后仍失败则上抛，**不产生伪决策** |
| 费用超限（M4） | 硬停，记 `BUDGET_EXHAUSTED` |

### 8.6 测试要求

- 无密钥行为（hermetic，`os.environ` 控制）；
- MockProvider 确定性与 `is_real_model=False`；
- `TracedClient` schema 校验拒绝矩阵；
- CallTrace 字段完整（hash/token/latency/attempts）；
- 回归：`test_llm_policy.py` / `test_llm_exploration.py` 全过；
- **真实调用测试仅限 `scripts/verify_llm_provider.py` 连通性探测**（不在测试套件内）。

### 8.7 版本兼容性

`LLMProvider` Protocol 签名不变；`ModelConfig` 只增字段（如 `cost_per_1k_tokens`）；
`CallTrace.as_dicts()` 只增字段。

## 10. 接口间调用关系（时序摘要）

```
Explorer.explore
  ├─ ScenarioRegistry.require(id, version)        # 锁定场景版本
  ├─ Budget / ToolSpec 构建（allowed_origins 真实 origin）
  ├─ loop:
  │    PlaywrightAdapter.observe → Observation v2
  │    ContextBuilder.build(...) → DecisionContext
  │    Planner.propose(ctx) → ActionProposal | None
  │    PolicyValidator.check(proposal, ...) → PolicyDecision
  │    ToolGateway.authorize(call) → PlaywrightAdapter.execute
  │    执行后检查 → execution_result
  │    GoalEvaluator.evaluate(...) → goal_evaluation
  │    TraceRecorder.record(全链) → decision_id 链
  └─ finalize: goal_evaluation（独立） + stop_reason（独立）
```

**红线复述**：模型只产生 Proposal；执行只经 ToolGateway；verdict 只属 Goal Evaluator；
StopReason ≠ 业务结论；C05 不动；409 不解除。
