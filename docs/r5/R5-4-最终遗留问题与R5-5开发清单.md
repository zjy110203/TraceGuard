## 3. R5-5 开发清单（建议顺序）

1. **真实 LLM 接入（D8）**：`provider_from_env` 已就绪（DeepSeek/OpenAI 兼容）；需要：密钥管理、费用预算闸、真实推理标记翻转（`may_contain_real_inference`）、Explorer API 的 `llm` 策略解禁、决策环压测。
2. **场景扩展框架**：把 `SUPPORTED_SCENARIOS` 从单登录场景扩为可注册场景包（意图模板 + 起始决策 + 目标验证配置），配合真实 LLM 后由模型接管决策。
3. **目标评估增强**：元素级（testid/text/URL 正则）预期结果语法，替代纯 text_excerpt 包含判断（解决 L7）。
4. **身份与审批**：最小身份模块（本地账号 + 审批签名），让 reviewer 从审计字段升级为可验证身份（解决 L2）。
5. **驱动级取消/超时**：Playwright async API 或子进程隔离，实现动作中取消（解决 L3）。
6. **对象存储适配**：S3BlobStore 实现 + 一致性测试（解决 L4）。
7. **Benchmark 正式评估**：UI-FaultBench 准确率跑批与报告。
8. **Repair 自动执行**：修复沙箱 → 提案 → 人工批准 → 版本晋升的完整闭环（**产品侧当前只能查看已有提案并批准/拒绝**：`/api/v1/repairs` 仅 4 个路由，无创建提案、无 promote；提案生成与 CAS 晋升只存在于库级 `repair.py` 与测试中）。
