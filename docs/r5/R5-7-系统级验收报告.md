## 10. 遗留风险与建议（不掩饰）

1. **单机串行**：长稳是单进程串行全链，未覆盖并发多任务竞争；若后续要支撑多用户，需要补并发写入与浏览器池限流测试。
2. **图谱布局**：单环布局在节点 >40 时分簇不足，需分层或力导向布局；后端邻接查询已支持分页，但前端暂未使用「加载更多」。
3. **诊断不落库**：`/runs/{id}/diagnosis` 为按需计算，页面已如实标注；若需历史对比，应增加落库表与迁移。
4. **迁移路径**：历史上存在 `create_all` 建库、无迁移态的库，恢复时需 `stamp base` 兜底；建议后续统一走 Alembic 初始化。
5. **LLM 面未验证**：受 D8 限制，真实 LLM 决策、成本与延迟未测；仅验证了未授权时返回 409 的诚实降级。
