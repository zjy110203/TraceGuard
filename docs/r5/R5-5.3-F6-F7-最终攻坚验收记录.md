## 事务协议与边界

同一 case 的正式创建、Repair 创建、晋升与回滚共用以目录和 case_id 为键的进程内锁；RepairStore 快照另受 service 锁保护。正式版本在锁内重新读取磁盘并核对 base version/digest；目标文件或事务预留存在时拒绝其他 Proposal，即使内容相同也不能认领。

持久化唯一 transaction_id、Proposal、case、base version/digest、target version、candidate digest、完整存储 envelope 和操作者审计，再写临时文件、flush/fsync、os.replace、COMMITTED，最后写 Proposal PROMOTED 和 DONE。恢复必须同时匹配 durable intent、完整文件内容及 envelope 中的事务所有权。没有文件的 intent 保持可安全重试；不一致文件保留并 BLOCKED；DONE 重复恢复不追加错误 Promotion/Audit。

回滚以新事务追加 v3，内容恢复 v1，保留 v1/v2；存储 envelope 记录 rollback_of_version=1，审计关联原 Proposal/Promotion、Operator、理由和新的 Rollback ID。活动 TestCase schema、Ground Truth 均未修改；loader 仅识别正式文件 envelope metadata。

该并发协议仅用于 Windows 本机、单用户、loopback、单进程/单 Worker。**不支持多进程并发，不宣称具备跨进程 CAS 或机器断电级存储保证。** 自由文本审核人仍是本机审计字段，不是身份认证。
