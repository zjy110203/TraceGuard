# R5-5.4 源码与安全复审

范围：本轮新增 Python/FastAPI、Vue 与离线存储工具；参考 security-best-practices 的 FastAPI/Vue 指引。不是企业安全认证。

已落实：Candidate id/case id 校验、同目录原子替换、正式文件不覆盖、所有权摘要核验、Candidate→Case 锁序、人工门禁不删除、前端插值不使用 v-html、不执行用户代码、不引入 shell 命令字符串、不读写真实 LLM 配置或秘密。

新增备份恢复先验证摘要/文件类型，再复制到新目录；递归目标拒绝，保留原数据。GT 导入严格比对批准的 base 与完整行集合，拒绝未经人工决定的导入；不激活真实标签。

保留限制：reviewer 为本机审计字段；进程内锁只支持单 Worker；本机文件 SHA-256 不构成抗恶意管理员的身份/签名；离线备份依赖停机前提；尚未获得 Generator/GT/D8 正式批准。没有将这些限制伪装成多用户认证、分布式事务或企业治理。

完整 Security 门禁除原九组测试，新增 Candidate 原有/事务、GT 导入与备份恢复测试。执行结果和修复记录见总验收报告。
