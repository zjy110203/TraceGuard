## 1. 本会话实现的架构增量

```
TestIntent -> TestCaseVersion(append-only)
   -> [阶段2] LocatorRegistry + Playwright(真 Chrome) + Trace/DOM/Network 证据
   -> [阶段2] OracleEvaluator(只读独立状态/UI) -> frozen Verdict(四态) -> Run/Step 报告
   -> [阶段3] Task(逻辑) -> Run(每次执行/attempt 递增/append-only) -> Step
                -> Orchestrator(进程内 worker + heartbeat + timeout + cancel)
                -> EventBus(单调 sequence / Last-Event-ID 回放) -> SSE 工作台
   -> [阶段4] EventStore(幂等/可信 workspace/缺口 PENDING_CONFIRMATION)
              Outbox(至少一次) + ConsumerInbox(消费幂等)
              EvidenceManager(raw/normalized/derived 分离 + SHA-256 + 脱敏 + 生命周期)
```

四个结果维度始终分离：`execution_status` / `test_verdict` / `diagnosis_status=NOT_STARTED` / `diagnosis_outcome=NOT_STARTED`。诊断属阶段 7，此处保持未开始，不伪造。
